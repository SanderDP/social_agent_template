# Copyright-check

Voor elke video moet `weeks/<jaar-week>/video-0N/bronnen.md` bestaan met elk extern element.
Controleer per regel:

| Element | Toegelaten als |
|---|---|
| Stockbeeld/-video | Pexels of Pixabay, link naar de originele pagina staat erbij; herkenbare personen alleen als het beeld commercieel bruikbaar is en niet in een drinkcontext die hen in een slecht daglicht stelt |
| Muziek/geluid in de MP4 | Zelfgemaakt (script vermeld) of stilte |
| Muziek bij het posten | Concreet nummer uit de commerciële bibliotheek van het platform, genoemd in het postvoorstel |
| Lettertype | Uit `remotion/public/fonts/` (OFL) |
| Logo's | Enkel van het eigen merk |
| App-beelden | Eigen app, demo-data met verzonnen namen |
| Personen | Geen herkenbare echte personen zonder schriftelijke toestemming |
| Andermans content | Nooit in de MP4. Remix/Stitch/Duet enkel via het platform zelf |

Ontbreekt `bronnen.md` of staat er een element zonder geldige bron in: minstens AANPASSEN.
Twijfel over rechten: AFKEUREN of het element vervangen.
